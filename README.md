# Grade Calculator 

A Python project to calculate student grades, percentage and rank.

## Features
- Add multiple students
- Calculate total marks and percentage
- Assign grades (A+, A, B, C, D, Fail)
- Assign rank (Distinction, First Class, Second Class)
- Pass/Fail status per subject
- Compare students and find topper
- Export results to CSV file

## How to Run
python grade_calculator.py

## Technologies Used
- Python 3.12
